# EduSphere – Student Management System

## 📌 Project Overview

**EduSphere** is a modern, responsive **frontend-only Student Management System** designed to provide a simple and professional interface for managing academic activities.

The project is developed using **HTML, CSS, and JavaScript**. It contains multiple connected pages for students, faculty, courses, attendance, marks, profiles, and settings.

> **Note:** This version is frontend-only. No backend server or database is required.

## 🎯 Objectives

* Provide a clean and user-friendly student management interface.
* Connect different academic pages through navigation.
* Create a responsive dashboard for students and administrators.
* Organize student, faculty, course, attendance, and marks information.
* Demonstrate frontend web development skills.

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Client-side interactions
* **VS Code** – Development environment
* **Live Server** – Local project preview
* **Git & GitHub** – Version control and project hosting

## 🚀 How to Run

### Method 1 – VS Code Live Server

1. Open the **EduSphere** folder in VS Code.
2. Open the `frontend` folder.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The project will open in your browser.

### Method 2 – Direct Browser

You can also open `index.html` directly in a web browser.
